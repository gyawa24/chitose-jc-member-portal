# 引き継ぎガイド

## このPWAで引き継ぐもの

- メンバーが日常的に使うリンクの入口
- JCを学ぶための公式リンク
- 議案チェックの観点と手順
- 予定・出欠のリンク
- 資料置き場のカテゴリ
- 4月AI例会アーカイブへの導線

## 担当者が毎年確認すること

1. 年度表記が古くないか確認する。
2. アジェンダシステム、出席表、発番表のリンクを新年度版に差し替える。
3. 委員会出欠、年間予定、Googleカレンダーのリンクを追加する。
4. リンク切れがないか確認する。
5. 認証情報や個人情報が掲載されていないか確認する。
6. 公開前に理事長、専務、担当理事などの確認を受ける。

## ふだん編集するファイル

通常は `data/portal-data.json` だけを編集します。

編集対象の例:

- `title`: カード名
- `description`: 説明文
- `url`: リンク先
- `status`: 「リンク未設定」などの注意表示

画面のデザインや動きまで変える場合だけ、`styles.css` や `app.js` を編集します。

## 掲載してはいけないもの

- GoogleアカウントのID、パスワード
- アジェンダシステム等のログイン情報
- Cookie、トークン、シークレットキー
- 個人情報を含む名簿や未公開資料の本文
- 公式資料や外部サイトの本文・画像・PDFの無断転載

## 公開前チェック

- スマートフォンでホーム、JCを学ぶ、議案チェック、予定・出欠、資料置き場が開ける。
- 主要リンクが別タブで開ける。
- 検索欄で「出席」「議案」「アワード」などが見つかる。
- ホーム画面に追加したとき、アプリ名が「千歳JC」になっている。
- 古い年度のリンクが残っている場合は、説明文で分かるようにする。

## Google Sitesとの使い分け

- PWA: メンバーが毎日スマートフォンで開く入口。
- Google Sites: 例会コンテンツや長めの説明、アーカイブ。
- Google Drive: 実ファイルの保管場所。
- Google Sheets: 出欠、発番、将来的なリンク管理データ。

この役割分担にすると、PWAは軽く保ちつつ、既存のGoogle運用を捨てずに引き継げます。
