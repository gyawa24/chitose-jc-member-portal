# 運用Runbook

## 通常更新

1. `data/link-inventory.csv` を見て、更新対象のリンクと担当者を確認する。
2. `data/portal-data.json` の該当カードを更新する。
3. 認証情報、個人情報、未公開資料本文が入っていないか確認する。
4. `npm run check` を実行する。
5. ローカルでスマートフォン幅とPC幅を確認する。
6. 公開前チェック担当者に確認してもらう。

## リンクを追加するとき

追加先は次の基準で決めます。

- 毎月使う: ホームの重要リンク
- 学習・公式資料: JCを学ぶ
- 議案提出前の確認: 議案チェック
- 出欠・予定: 予定・出欠
- ファイル置き場: 資料置き場
- 過年度例会やデモ: 例会コンテンツ
- その他実務: 関連リンク

## リンクが未確定のとき

未確定のリンクは削除せず、`status` に `リンク未設定` を入れます。
メンバーに「まだ未整備である」と分かるほうが、古いリンクを残すより安全です。

## 公開前チェック

- `npm run check` が通っている。
- ホーム、JCを学ぶ、議案チェック、予定・出欠、資料置き場が開ける。
- 検索で「出席」「議案」「アワード」「発番」が見つかる。
- 外部リンクが別タブで開く。
- 認証情報が掲載されていない。
- 4月AI例会アーカイブへの導線が残っている。
- スマートフォンで横スクロールが出ていない。

## 障害時

### ページが真っ白になる

`data/portal-data.json` のJSON形式が壊れている可能性があります。
`npm run check` を実行して確認してください。

### リンクが開けない

リンク先の権限、URL変更、年度切替の可能性があります。
`data/link-inventory.csv` の担当者に確認してください。

### ホーム画面追加が出ない

ブラウザやOSによって表示方法が異なります。
HTTPSで公開されているか、`manifest.webmanifest` と `sw.js` が読めるかを確認してください。

## 年度切替

年度切替時は `docs/annual-update-checklist.md` を使います。
リンク差し替えだけで済まない場合は、`docs/decision-log.md` に判断を記録してください。
