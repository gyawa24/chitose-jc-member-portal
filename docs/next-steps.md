# 次の進め方

## 第1段階: 試作確認

- ローカルで画面を確認する。
- スマートフォン表示で迷わず使えるか確認する。
- 足りないリンクを洗い出す。

## 第2段階: 管理方法を決める

候補は2つです。

- `data/portal-data.json` を直接編集する。
- Google Sheetsでリンク一覧を管理し、PWAに読み込ませる。

引き継ぎやすさを最優先するなら、Google Sheets管理が向いています。
ただし公開範囲と権限設計を先に決める必要があります。

## 第3段階: 公開先を決める

小さく始めるなら GitHub Pages、将来の拡張を考えるなら Vercel または Firebase Hosting が候補です。

## 第4段階: 本番化

- アイコンの正式化
- Google Sheets連携
- 年度切り替え手順の固定化
- 管理者向け更新チェックリストの整備
- PWA公開URLのQRコード化
