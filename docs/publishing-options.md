# 公開先の候補

## 候補1: GitHub Pages

向いている場合:

- 費用をかけずに始めたい
- 静的PWAとして運用したい
- 更新履歴を残したい

注意点:

- GitHubの扱いに慣れていない担当者には少し難しい
- Google Sheets連携などを増やす場合は設計が必要

## 候補2: Vercel

向いている場合:

- 今後、検索や管理画面などを拡張したい
- 更新の確認環境を作りたい
- 将来的にReact/Next.js化する可能性がある

注意点:

- アカウント管理と権限移譲が必要
- 無料枠で足りるかは運用量を見て判断する

## 候補3: Firebase Hosting

向いている場合:

- Googleアカウント中心で管理したい
- 将来、認証やデータベースを使う可能性がある

注意点:

- 初期設定がやや専門的
- 担当者交代時にGoogle Cloud/Firebase権限の引き継ぎが必要

## 現時点のおすすめ

まずは静的PWAとして小さく公開し、Google DriveやGoogle Sheetsへの入口に徹するのが安全です。
次年度以降に担当者が慣れてきたら、Google Sheets管理や通知機能を足すのがよいです。
