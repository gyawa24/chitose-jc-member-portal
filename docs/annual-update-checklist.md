# 年度更新チェックリスト

## 1. 新年度リンクへ差し替える

- アジェンダシステム
- 例会等出席スプレッドシート
- 理事会出席スプレッドシート
- 対外資料発番スプレッドシート
- 年間予定
- 委員会出欠
- 議案フォーマット
- 議事録・事業資料・過去例会資料のDriveフォルダ

## 2. 表記を確認する

- 年度表記が古くないか
- 担当者名や役職名が古くないか
- 「リンク未設定」のままでよい箇所か
- 例会コンテンツが過年度アーカイブとして分かるか

## 3. 掲載してはいけない情報がないか確認する

- パスワード、暗証番号、ログイン情報
- 個人情報
- 非公開資料の本文
- 外部サイトやPDFの本文・画像の転載

## 4. スマートフォンで確認する

- ホーム画面に追加できるか
- 下部ナビが押しやすいか
- 主要リンクが開けるか
- 検索で「出席」「議案」「アワード」「発番」などが見つかるか

## 5. 公開前の確認者

- 担当委員会
- 事務局
- 専務
- 理事長または確認権限者

公開URLを差し替える場合は、QRコード、LINE、Google Sites、資料内リンクも合わせて更新します。
