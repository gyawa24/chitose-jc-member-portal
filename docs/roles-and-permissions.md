# 役割と権限

## 想定ロール

### ポータル管理担当

- PWAのリンク、説明文、年度表記を更新する。
- `data/portal-data.json` と `data/link-inventory.csv` を管理する。
- 公開前チェックを取りまとめる。

### 事務局

- アジェンダ、出席表、発番表、年間予定のリンクを確認する。
- 公開範囲と権限が適切か確認する。

### 各委員会

- 委員会出欠、事業資料、例会資料のリンクを提供する。
- 古い資料や誤ったリンクがあれば管理担当に連絡する。

### 確認者

- 公開前に内容、権限、表記、リンクを確認する。
- 予算、契約、個人情報、対外資料が関わる場合は人間が最終確認する。

## 権限の考え方

- PWA自体は入口として公開範囲を広くしやすい。
- 実ファイルの閲覧権限はGoogle Drive/Sheets側で管理する。
- 非公開資料はPWAに本文を載せず、権限付きリンクだけにする。
- URLを知っている人なら見られる設定にする場合は、担当者と確認者で合意してからにする。

## 引き継ぎ時に渡すもの

- 公開URL
- 管理リポジトリまたはファイル一式
- `data/link-inventory.csv`
- 公開先サービスの管理権限
- Google Drive/Sheets/Sitesの管理権限
- 年度更新チェックリスト

パスワードや個人アカウントの認証情報は渡さず、サービス側の権限移譲で対応します。
